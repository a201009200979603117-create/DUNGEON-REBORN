# DUNGEON REBORN

暗黑奇幻風格的 Roguelike 生存遊戲：深入地牢、撐過一波又一波怪物，擊敗 Boss 拿寶藏。

## 線上玩
https://a201009200979603117-create.github.io/DUNGEON-REBORN/

## 下載
到 [Releases](../../releases/latest) 下載：
- **Windows**：`DUNGEON.REBORN.Setup.1.0.0.exe`
- **Android**：`DUNGEON-REBORN-1.0.0.apk`（需允許安裝未知來源應用程式）

## 操作
- 電腦：WASD / 方向鍵移動，自動攻擊，P 暫停，M 靜音
- 手機：手指拖曳移動，建議橫向遊玩
